# Advanced E-commerce Sales & Profitability Dashboard

## Overview
This project presents an interactive Excel dashboard designed to analyze sales performance, profitability, customer behavior, and operational efficiency using e-commerce transactional data.

## Key Features
- KPI Tracking
- Profitability Analysis
- Customer Insights
- Discount Impact Analysis
- Interactive Slicers
- Time-based Reporting

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

## Key Insights
- Discounts above 30% reduced profitability
- Certain regions generated high sales but low profits
- Revenue concentrated among top customers
